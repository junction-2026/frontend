## Why
The VEIL site has no favicon: browser tabs show a generic icon. Shared project issue junction-2026/project#68 asks for a VEIL favicon set linked from `index.html`.

## What Changes
- New static assets in `public/`: `favicon.svg` (master), `favicon.ico`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `site.webmanifest`; rasters generated by `scripts/favicon.py` (Pillow) from the master SVG.
- Four `<link>` tags in `index.html` outside the `og:start`..`og:end` block.
- `nginx/default.conf.template`: `.webmanifest` content type override (the stock mime.types lacks it).
- Vitest test `nginx/favicon.test.ts`, extra checks in `scripts/og-smoke.sh`, README note.
- No shared-spec change, no new dependency, no change to `public/og`.

## Impact
Frontend only. Pinned shared spec: shared-specs@3949bec3d32a399427d239e3147239fa1e716cfe (not read or changed). The design is an assumed geometric "V"; a supplied logo can replace `public/favicon.svg` and be re-rendered with the script.
