## Decisions
- **Catalog keyed by stable id, one source.** `techniques.<id>.name|definition` for classifier names and LLM labels; `techniqueText` in `src/job/read.ts` is the only lookup, used by Results tags, Detail list, LLM group, highlights and aria labels, so every view shows the same term.
- **When the catalog is used.** `locale !== explanation_language` (shared "Client localization of glossary texts"). A result that names no language is English, except that one carrying `plain_language` is taken as already in the UI language. LLM findings without a stated language are taken as in the UI language.
- **Why.** Server `why` is kept unless the catalog localizes the technique; then the catalog template is filled with the localized name and the span text verbatim. A result without server `why` stays without one (shared "Result from before plain-language support").
- **Localization requests.** `needsLocalization(job, locale)`: job done, there is a `user_text` or an LLM finding, and a *known* text language differs from the UI language. Known = `translation.source_language`, English for a fixed orchestrator text, `llm_techniques` `explanation_language`. An unknown language never triggers a request. The cache holds promises per `(job id, language)` for the page lifetime; failed requests are dropped so a later switch may retry. A provider (`LocalizationProvider`, inside `WithJob`) fetches in an effect keyed by `(need, job, locale)`; the job fetch and the event stream do not depend on the locale.
- **Honest markers.** Only status `translated` with non-empty text is shown as localized. `original` shows the original; `unavailable`, an unknown status, an error or a missing entry shows the original plus the "not available" note. While loading the original is shown without note.
- **Activities and notes** are localized by key/params and reason in `AnalyzingView` and `Coverage` (shared analysis-job-events "Activity rendering", analysis-jobs-api "Availability note text"); unknown keys keep API text.
- **Not done:** a "translating" marker while the request is in flight; translation of Explore, claims and fact-check views (not owned by this change).
