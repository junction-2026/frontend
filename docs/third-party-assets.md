# Third-party assets

## Hostinger emblem (`src/assets/hostinger-emblem.svg`)
- **Source:** the official Hostinger emblem as served inline on https://www.hostinger.com/ (icon `ic-logo-hostinger-24`, viewBox 0 0 24 24). Downloaded 2026-11-15. The file is byte-for-byte the site's SVG; no paths or colours were changed.
- **Why not the media kit:** https://www.hostinger.com/media-kit returns 404, and the brand portal linked from https://www.hostinger.com/brand-guidelines (hostinger.dash.app) only works in a browser. The project owner approved this source and the "Powered by" use.
- **Colour:** the emblem uses `fill="currentColor"`. When it is loaded through `<img>`, it renders in the default dark ink, which is the variant for light backgrounds.
- **Guidelines applied (https://www.hostinger.com/brand-guidelines):**
  - the emblem isn't stretched, recoloured, rotated, or given shadows or effects;
  - it keeps clear space of at least 25% of its height (the guidelines publish no value);
  - it's shown on a light background.
